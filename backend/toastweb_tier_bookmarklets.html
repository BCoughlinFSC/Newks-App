How to use

  1. Open a menu item's edit page in ToastWeb.
  2. Click AUDIT first. It changes nothing — it lists every row it would revert, fix, or add, and everything it would leave alone.
  3. Then FIX IT. Same list, you confirm, and it saves once.
  4. Detail is logged to the DevTools console every time.

Safe to run on every item. It is idempotent: an already-correct item reports "nothing to do", an item that never got the bad reprice just gets its three Company Only rows added, and an existing Company Only row is corrected rather than duplicated. You do not need to remember which items you touched.

Only whole-label matches are acted on. Tier 8 - Dine In and Tier 8 - Dine In - Company Only are different rows; Tier 8 Catering, Tier 8 - Box Salad Price, Tier 7 & 8 - Box Sandwich & Wrap and Tier 8 - To Go are never touched.

Nothing is saved unless every edit verified. If a price did not stick, or an added row did not land with the right location and price, it stops without saving — reload the page to discard the partial edits.
