How do I import more Aloha data?

From the backend folder, run:

python import_aloha_data.py --sql --sql-start YYYY-MM-DD --sql-end YYYY-MM-DD

Or for the last 90 days: python import_aloha_data.py --sql-last-days 90

Configure ALOHA_SQL_* in backend/.env first (see Backend README → “Importing Aloha data”).

All stores: The query runs against your Aloha DB and can return every location (no store filter in the query).

By store: To break down by store in YoY reports, include a Location column in your SQL (e.g. StoreId AS Location). Then add backend/data/aloha/aloha_location_mapping.json mapping Toast restaurant GUIDs to Aloha store IDs so the app can filter Aloha data by the locations you select.
