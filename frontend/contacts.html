What lives here

This section is the in-app replacement for forms.nfc.local. Data still lives in SQL-PROD's contacts database, so existing SSRS reports and scheduled jobs keep working unchanged — we just put a cleaner UI on top.

All edits are audit-logged (who, what, when) in contacts.dbo.AuditDataChanges via the existing SQL Server triggers. Only admins can create / update / delete.
