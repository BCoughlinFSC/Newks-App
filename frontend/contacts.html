What lives here

This section is the in-app replacement for forms.nfc.local. Data lives in a local SQLite mirror that's refreshed from SQL-PROD periodically. Edits made here save immediately to the local copy; sync-back to SQL Server is on the roadmap.

Only admins can create / update / delete. Every change stamps LastUpdatedBy + LastUpdated so we have an audit trail to reconcile with SQL Server later.
