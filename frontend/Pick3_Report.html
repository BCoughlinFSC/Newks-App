How to export from Toast:
  1. In Toast Back Office, go to Reports → Menus → Product Mix
  2. Select your locations and set your date range and run the report
  3. Be sure the menu hierarchy is set to 7 levels
  4. Export → select CSV All Available Data
  5. Unzip the exported file and head back here to upload the CSVs
  6. Upload the CSVs below and click Load Breakdown
  • Check the reconciliation panel at the bottom of the page to confirm the data is accurate.
  • Export the data to Excel using the Export Excel button.

All levels.csv is required for accurate pairing counts — it contains the parent→pairing link. Items.csv and Modifiers.csv are optional fallbacks.
