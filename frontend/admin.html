Lubbock TX (Aloha POS)

Lubbock is still on Aloha — upload daily sales CSV from SSMS
SSMS Query Instructions

1. Open SSMS and connect to the Aloha SQL Server

2. Run the query below (change the dates as needed)

3. Right-click results → Save Results As → CSV

4. Upload the CSV below

SELECT
    CONVERT(VARCHAR(10), DateOfBusiness, 120)  AS business_date,
    '1188'                                      AS location,
    'Lubbock TX'                                AS restaurant_name,
    ISNULL(SUM(NetSales), 0)                   AS net_sales,
    ISNULL(SUM(OLONetSales), 0)                AS olo_net_sales,
    ISNULL(SUM(DeliveryNetSales), 0)           AS delivery_net_sales,
    ISNULL(SUM(CateringNetSales), 0)           AS catering_net_sales,
    ISNULL(SUM(GNGNetSales), 0)                AS gng_net_sales,
    ISNULL(SUM(ToGoNetSales), 0)               AS togo_net_sales,
    ISNULL(SUM(CurbSideNetSales), 0)           AS curbside_net_sales,
    0                                           AS curbside_olo_net_sales,
    ISNULL(SUM(DineInNetSales), 0)             AS dinein_net_sales,
    ISNULL(SUM(CallInNetSales), 0)             AS callin_net_sales,
    0                                           AS olo_callin_net_sales,
    ISNULL(SUM(CheckCount), 0)                 AS check_count,
    ISNULL(SUM(CheckCount), 0)                 AS checks_minus_catering
FROM dbo.tbl_SalesDataByDayPart
WHERE DateOfBusiness BETWEEN '2026-03-01' AND '2026-03-26'
  AND RestaurantID = '1188'
GROUP BY DateOfBusiness
ORDER BY DateOfBusiness
