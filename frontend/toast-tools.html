ToastWeb Bulk Edit Tools

One-click edits to the Location Prices table on a ToastWeb menu item, run in your own signed-in browser. Drag the buttons below onto your bookmarks bar, open a menu item in ToastWeb, and click them there.

Always click AUDIT first. It changes nothing — it lists exactly what FIX would do. FIX shows the same list and waits for you to confirm before it saves.

Nothing is saved unless every single edit is re-read and verified. If anything does not stick, it stops without saving — reload the page to discard partial edits.

These are safe to re-run. An item that is already correct reports "nothing to do", so you do not need to track which items you have done.

Adding a new job

  1. Copy a file in backend/toastweb_tools/jobs/ and edit the rules.
  2. Run python backend/toastweb_tools/build_tools_page.py.
  3. Commit, deploy, then re-drag that job's two buttons.

Rule types: setPrice (match → price), ensureRow (add if missing / correct if wrong), removeRow (match → delete).

The build refuses to publish a job whose match pattern is not anchored ^...$, that collides with its own ensureRow labels, or that hits a known near-miss label such as Tier 8 - Dine In - Company Only. Every button is syntax-checked before the page is written.
