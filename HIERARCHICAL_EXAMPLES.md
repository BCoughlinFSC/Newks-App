## 🎯 How to Use This

### **Step 1: Generate Hierarchical Report**

```python
from sales_consolidator import SalesConsolidator
from hierarchical_reports import HierarchicalReportGenerator
import pandas as pd

# Initialize
consolidator = SalesConsolidator("enhanced_mapping.xlsx")
hierarchy_gen = HierarchicalReportGenerator(consolidator)

# Load your data
aloha_df = consolidator.load_aloha_data("aloha_nov_2024.xls")
toast_df = pd.read_excel("toast_nov_2025.xlsx")  # Or from your API

# Consolidate Toast data
toast_consolidated = consolidator.consolidate_toast_data(
    toast_df,
    guid_col='menuItemGuid',
    qty_col='quantitySold',
    sales_col='netSalesAmount'
)

# Compare
comparison = consolidator.compare_yoy(
    aloha_df, 
    toast_consolidated,
    aloha_period="Nov 2024",
    toast_period="Nov 2025"
)

# Generate hierarchical structure
hierarchy = hierarchy_gen.generate_hierarchical_comparison(
    comparison,
    period1_label="Nov 2024",
    period2_label="Nov 2025"
)

# Print to console
hierarchy_gen.print_hierarchical_report(
    hierarchy,
    show_top_items=5,      # Show top 5 items per category
    show_bottom_items=3    # Show bottom 3 items per category
)

# Export to Excel
hierarchy_gen.export_hierarchical_excel(
    hierarchy,
    "november_2024_vs_2025_hierarchical.xlsx"
)
```

### **Step 2: Add Location Breakdown**

```python
# Consolidate WITH location breakdown
toast_by_location = consolidator.consolidate_toast_data(
    toast_df,
    guid_col='menuItemGuid',
    qty_col='quantitySold',
    sales_col='netSalesAmount',
    location_col='restaurantName'  # ← This adds location dimension
)

# Compare with locations
comparison_by_location = consolidator.compare_yoy(
    aloha_df, 
    toast_by_location,
    aloha_period="Nov 2024",
    toast_period="Nov 2025"
)

# Generate location hierarchy
location_hierarchy = hierarchy_gen.generate_location_hierarchy(
    comparison_by_location,
    period1_label="Nov 2024",
    period2_label="Nov 2025"
)

# Print location hierarchy
hierarchy_gen.print_location_hierarchy(
    location_hierarchy,
    show_top_locations=3,     # Top 3 locations per category
    show_bottom_locations=2   # Bottom 2 locations per category
)
```

## 💡 What You Can Answer with These Reports

### **From Company-Wide Hierarchy:**
✅ "Which categories are growing fastest?" → See Category Summary
✅ "What items are driving catering growth?" → Drill into Catering category
✅ "What soup items are declining?" → See bottom items in Soups category
✅ "Overall company performance?" → See TOTAL row in summary

### **From Location Hierarchy:**
✅ "Which locations have strongest soup sales?" → See top locations in Soups
✅ "Why is Mobile, AL performing so well?" → See their top items
✅ "Which locations need help with salads?" → See bottom locations in Salads
✅ "What's working at Fort Collins that we can replicate?" → See their winning items

## 🎨 Customization Options

You can adjust the reports:

```python
# Show more/fewer items per category
hierarchy_gen.print_hierarchical_report(
    hierarchy,
    show_top_items=10,     # More winners
    show_bottom_items=5    # More losers
)

# Show more/fewer locations
hierarchy_gen.print_location_hierarchy(
    location_hierarchy,
    show_top_locations=5,     # Top 5 instead of 3
    show_bottom_locations=5   # Bottom 5 instead of 2
)

# Filter to specific categories
soup_only = {
    'hierarchy': [h for h in hierarchy['hierarchy'] if 'Soup' in h['category']],
    'period1_label': hierarchy['period1_label'],
    'period2_label': hierarchy['period2_label']
}
hierarchy_gen.print_hierarchical_report(soup_only)
```
